Nova Studio 3.4.6（Windows）

■ 新增功能

· 用量与成本看板（侧栏新增 Tab）
  按天 / 按模型 / 按工作类目统计花费，可切近 7 / 30 / 90 天。
  · 生图：0.015 元/张（只计成功出图的张数，失败不计）
  · 对话与视觉：按 token 计，缓存命中 0.02（空闲）/ 0.04（高峰），
    未命中 1 / 2，输出 4 / 8（元/百万 token），高峰 = 周一至周五 09:00-12:00、14:00-18:00（北京时间）
  · 面板底部写明当前价目表与是否处于高峰计价时段；单价可用环境变量覆盖

· 出图自检（异步，不拖慢出图）
  出图后自动把「参考图 + 结果图」交给视觉模型比对，检查：
  画面文字被凭空添加（参考图没有的角标/数量标注）、件数不符、商品变形、
  包装文字错误、缺件。结论以角标标在图上（⚠ 数量 / ✓），
  图片详情里可看每条问题，也可手动点「自检 / 重新自检」补跑。
  Agent 头部「自检」按钮可整体开关，默认开启。

■ 修复

· 生图任务未记录工作类目，导致看板「按工作类目」统计恒为空
· 本地字段可能被一并转发给上游（严格的上游会返回 400）
· 流式响应的 token 用量未被记账（Responses 协议的 usage 位于 response 内部）
· 用量看板新增后前端测试断言未同步（不影响功能，本次一并修正）

■ 升级须知

· 数据目录自 3.4.5 起迁到 %APPDATA%\<应用名>，更新不再影响记忆 / 模型配置 / 生成图
· 首次打开约 15 秒后会提示「新版本已下载完成」，点重启即可完成更新
· HK 版（全量记忆种子：捏捏乐 / 通用 / 美妆）与 L 版（仅通用）请各取所需，
  两条更新通道互不干扰
